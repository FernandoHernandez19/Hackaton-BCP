# Instrucciones para Claude Code

- Lee [README.md](README.md) y [MVP.md](MVP.md) antes de trabajar.
- Resuelve solo la tarea asignada.
- Antes de editar, comprueba la rama actual y si hay cambios sin guardar (`git status`). Consérvalos.
- No programes directamente sobre `main`: trabaja en una rama `tarea/...`.
- No cambies el stack, las dependencias ni el diseño global sin acuerdo del equipo.
- Si la tarea toca archivos compartidos, avisa al usuario para que lo coordine antes.
- Prefiere soluciones sencillas que el equipo (principiante) pueda entender y mantener.
- Ejecuta las comprobaciones disponibles (las documentadas en README.md).
- Al terminar, resume: qué cambió, cómo se probó y qué falta.
- No afirmes que algo funciona si no lo comprobaste.
- No hagas push, no abras ni integres pull requests salvo autorización explícita del usuario.
- Nunca incluyas contraseñas, tokens ni archivos `.env` en los cambios.
